# Universal Glass Effect

A Windows customization mod for Windhawk that attempts to apply Acrylic and Glass transparency effects to application windows.

## Features

- Acrylic blur effect.
- Transparent window appearance.
- Support for multiple Windows applications.
- Global application targeting through Windhawk.
- Customizable glass color and transparency.

## Requirements

- Windows 10 or Windows 11.
- Windhawk.

## Installation

1. Install Windhawk.
2. Download the `.wh.cpp` source file.
3. Create a new mod in Windhawk.
4. Paste the source code.
5. Compile and activate the mod.

## Compatibility

The effect depends on Windows composition APIs and individual application rendering methods. Some applications may not support the effect fully.
